# v1 — Basic release

**Status:** In progress on `release/v1` (ready for validation)  
**App version:** `v1.0`  
**Code version:** `v1r16` (increment `code-version` + `version.json` on each code change; bump app version only when releasing a new user-facing version)  
**Git:** branch `release/v1`, tag `v1.0.0` when shipped

---

## Summary

Minimal portfolio tracker: companies and interest-style projects only. No bottom navigation, no settings, no themes. **Forms store company totals**; **list cards show your share** (total ÷ partners). Includes sample data and anonymous user count (Netlify).

---

## Amount rules (v1)

| Where | What is shown |
|--------|----------------|
| **Project form** | Company totals — Total Investment, Total Expected Return |
| **Main page company card** | **My share** invested (sum of project totals ÷ partners) |
| **Company detail project card** | **My share** per project (project total ÷ partners) |
| **Project detail** | Company totals **and** my share (totals ÷ partners) |

**Compact amounts on cards:** `$1M` / `$1.2M` at ≥ $1M; otherwise `$Nk` or full dollars.

## Technical notes

- **Branch:** develop on `release/v1`; full app stays on `main`.
- **Deploy:** Netlify manual upload or CLI; include functions + `package.json`.
- **Cache:** bump `code-version` in `index.html` and `version.json` together; CSS/JS `?v=` matches code version.
- **Data:** `localStorage`; projects default to type `lent_interest` internally for storage compatibility.
