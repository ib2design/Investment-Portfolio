# v1 — Basic release

**Status:** In progress on `release/v1` (ready for validation)  
**App version:** `v1.0`  
**Code version:** `v1r9` (increment `code-version` + `version.json` on each code change; bump app version only when releasing a new user-facing version)  
**Git:** branch `release/v1`, tag `v1.0.0` when shipped

---

## Summary

Minimal portfolio tracker: companies and interest-style projects only. No bottom navigation, no settings, no themes. All amounts are **group totals**. Includes sample data helpers for production onboarding.

---

## In scope

### App shell & navigation

- [x] Single-page flow: portfolio → company → project (back button only)
- [x] No bottom navigation (Portfolio / Reminders / Reports / Settings removed from UI)
- [x] No header logo or in-app icon
- [x] No PWA manifest / favicon / apple-touch-icon links in `index.html`
- [x] App title: plain text **Investment Portfolio** (same font, normal color — not red/orange split)
- [x] No Group vs My Share toggle; all amounts default to **group total**
- [x] No amount-mode label under app name
- [x] Version check on open: `version.json` fetched fresh; auto-reload when `codeVersion` changes (`js/bootstrap.js`, `js/versionCheck.js`)

### Main page (portfolio)

- [x] List all companies (no active/past filter)
- [x] Company card: **name**, **total investment** (group total, all projects), **project count**, **partner count**
- [x] No unicode icons on company cards
- [x] No orange FAB; blue **Add Company** button after last company card
- [x] **Add Sample Data** — creates fixed sample company + 2 projects (see below); alerts if sample already exists
- [x] **Delete Sample Data** — removes sample company and its projects; alerts if none exists
- [x] Sample buttons side-by-side under Add Company (production feature)

- [x] **Company name** (required)
- [x] **Number of partners** (required, default 1)
- [x] **Edit** in header on company detail; **Delete company** on edit form
- [x] No documentation link field

### Company detail

- [x] Company card: **name · X projects · Y partners** on one line (no stats block, no doc link, no icons)
- [x] Section header: **Projects**
- [x] Project cards: **project name** + **total invested** only (no icons, status, dates on card)
- [x] No orange FAB; blue **Add Project** after last project (or under company card if no projects)
- [x] **Edit** in header → company form

### Add / edit project

- [x] **Project name** (required)
- [x] **Date invested** (required; no “Today” button)
- [x] **Total investment** (required)
- [x] **Maturation date** (optional; no “Today” button)

- [x] Shows: project name, date invested, total investment
- [x] Maturation date and expected return shown only when set
- [x] **Edit** in header → project form

## Technical notes

- **Branch:** develop on `release/v1`; full app stays on `main`.
- **Deploy:** manual (local server or Netlify); bump `code-version` in `index.html` and `version.json` together.
- **Cache:** CSS/JS cache-bust via `?v=` matching `code-version`; PWA may need one Safari refresh after version-check code was first added.
- **Data:** `localStorage`; projects default to type `lent_interest` internally for storage compatibility.
